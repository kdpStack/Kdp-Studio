### 1.2 Core Technology: What is "Murdoku"?

**Murdoku** = Murder + Sudoku-style logic grid puzzles

A Murdoku puzzle is a **story-driven logic grid puzzle** where:
- Solvers must deduce relationships between categories (suspects, locations, weapons, times, etc.)
- Each puzzle has a crime/mystery narrative (murder investigation or heist)
- Clues are provided in written form requiring deductive reasoning
- Grid-based solution tracking (similar to Einstein's Riddle / Zebra Puzzle)
- **Single verified solution** - every puzzle must have exactly one logical solution

### 1.5 Difficulty Level System

1. **Beginner** - Simple 6×6 grids, obvious clues, minimal deduction chains
2. **Easy** - 8×8 grids, straightforward logic paths
3. **Medium** - 10×10-12×12, moderate clue complexity
4. **Hard** - 14×14, multi-step deductions required
5. **Dragon/Expert** - 16×16, complex interdependent clues, long deduction chains
