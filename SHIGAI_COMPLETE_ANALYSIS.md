## What is Shigai Royalty?

Shigai Royalty is a cloud-based software platform designed to help self-publishers, KDP sellers, and digital product creators produce **Murdoku-style mystery logic puzzle books** without manual puzzle construction. The name "Murdoku" combines "Murder" + "Sudoku" - referring to story-driven logic grid puzzles where solvers deduce who committed a crime based on logical clues.

### The Murdoku Puzzle Format

A Murdoku puzzle consists of:
- **A setting** (typically a mansion, estate, or location with multiple rooms)
- **Suspects/Characters** (6-16 depending on grid size)
- **Rooms/Locations** within the setting
- **Logical clues** (all statements are TRUE)
- **One solution** - the suspect alone with the victim in a specific room

The solver uses deductive reasoning to place each suspect in a room, and whoever ends up alone with the body is the culprit.

### Algorithm Foundation
- **Latin Square Generation** - ensures valid grid structures
- **Constraint Propagation** - validates clue consistency
- **Backtracking Solver** - counts solutions to verify uniqueness
- **Clue Generation Logic** - creates interconnected, solvable statements

### Data Flow
1. User selects grid size + difficulty
2. Engine generates Latin square foundation
3. Suspects/rooms assigned to grid positions
4. Clues generated from logical relationships
5. Solver verifies single unique solution
6. If multiple solutions → regenerate
7. If valid → format for export
8. User downloads print-ready files
